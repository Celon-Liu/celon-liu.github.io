Privacy Policy · 隐私政策

Finder · Last updated: 2026-10-10

1. Who we are · 我们是谁

Finder is a desktop application our team uses to prepare search and website reports for businesses that sell abroad. It is not offered to the public; the only person who signs in with Google is Finder's operator.

Finder 是我们团队自用的桌面工具，为出海企业制作搜索与网站分析报告。它不对公众开放，用 Google 登录的只有 Finder 的运营者本人。

2. What Google data we access · 我们读取哪些 Google 数据

With the operator's consent, Finder requests read-only access to:

  • Google Search Console (webmasters.readonly): clicks, impressions, average position, queries, pages and countries of the sites that clients have added the operator's account to;
  • Google Analytics (analytics.readonly): sessions, traffic sources, landing pages, events and key events of the properties that clients have added the operator's account to.

It also reads the operator's own email address (openid, email), only to show which account is connected.

Finder does not read email, contacts, files or any other Google data, and never creates, changes or deletes anything in a Google account.

经运营者同意，Finder 以只读方式读取：客户已授权给运营者账号的 Search Console 网站数据（点击、展示、平均排名、搜索词、网页、国家），以及 Google Analytics 媒体资源数据（访问、来源、着陆页、事件和关键事件）。Finder 不读取邮件、联系人、文件等其他 Google 数据，也不会创建、修改或删除 Google 账号里的任何内容。

3. How we use it · 用途

The data is used only to prepare the report the client asked for, and the monthly follow-up the client agreed to. It is not used for advertising, not sold, and not shared with anyone other than the client it belongs to.

To write the report, excerpts of the data (numbers and page addresses, not account credentials) are sent to Anthropic's Claude model for analysis. Anthropic processes them to return the analysis; we have turned off the account setting that would let Anthropic use our conversations to improve its models.

数据只用于制作客户委托的报告，以及客户同意的每月跟进。不用于广告，不出售，不提供给除数据所属客户以外的任何人。写报告时，数据的节选（数字和网页地址，不含账号凭证）会发送给 Anthropic 的 Claude 模型做分析；我们已在 Claude 账号里关闭「允许用对话改进模型」的设置。

Finder's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Finder 对通过 Google API 获得的信息的使用和传输，遵守《Google API 服务用户数据政策》，包括其中的「有限使用」要求。

4. Where it is stored · 存放在哪里

Data read from Google is stored only on the operator's own computer, in the client's report folder. The sign-in token is stored encrypted on that computer. Nothing is stored on our servers.

从 Google 读到的数据只保存在运营者自己的电脑上、该客户的报告文件夹里；登录凭证在这台电脑上加密保存。我们没有服务器存放这些数据。

5. How long, and how to remove it · 保存多久、如何删除

A client's data is kept for as long as we work with them, and deleted when the work ends or whenever they ask. A client can stop access at any time by removing the operator's account in Search Console (Settings → Users and permissions) or Google Analytics (Admin → Property access management). The operator can revoke Finder's access at myaccount.google.com/permissions.

客户的数据在合作期间保留，合作结束或客户要求时删除。客户随时可以在 Search Console（设置 → 用户和权限）或 Google Analytics（管理 → 媒体资源访问权限管理）里移除运营者账号，停止授权。
