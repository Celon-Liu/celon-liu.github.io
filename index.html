Finder

Data reports for businesses selling overseas · 出海获客数据分析

Finder is a desktop application used by our team to prepare search and website reports for businesses that sell abroad. It reads public Google search results and a client's own website, and — only when the client grants access — the client's Google Search Console and Google Analytics data, read-only.

Finder 是我们团队自用的桌面工具，为做出海生意的企业制作搜索与网站分析报告。它读取 Google 公开搜索结果和客户自己的网站；只有在客户授权后，才以只读方式读取客户的 Google Search Console 和 Google Analytics 数据。

How Google data is used · Google 数据的用途

Finder uses Google sign-in only for its operator's own Google account, to read the Search Console sites and Analytics properties that clients have added that account to. The data is used solely to write the report the client asked for. Finder never changes anything in a client's Google account.

Finder 只用于运营者本人的 Google 账号，读取客户已把该账号加为用户的 Search Console 网站和 Analytics 媒体资源。数据只用于制作客户委托的报告，Finder 不会修改客户账号里的任何内容。
